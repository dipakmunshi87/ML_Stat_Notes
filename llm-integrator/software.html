Libraries

What to install

Learned dynamics

torchdiffeq — neural ODEs with adjoint gradients, including symplectic-friendly solvers.

diffrax — the JAX equivalent, with a wider solver set and better support for structure-preserving schemes.

hamiltonian-nn — the reference implementation of learning a Hamiltonian rather than a step.

Doing it properly

DifferentialEquations.jl — the most complete set of symplectic and structure-preserving integrators anywhere, and the easiest place to compare a learned map against a proper scheme.

OpenMM and LAMMPS — if the learned object is a force field, these are where the energy-drift diagnostics already live.

Write it yourself

The code behind these pages is about 500 lines of plain JavaScript with no dependencies: a tape for automatic differentiation, causal attention, a softmax over a vocabulary, and a spring.

Building one is the fastest way to stop treating a language model as something categorically different from a recurrence relation. An afternoon.

The one to reach for first

Whatever you are building, get a classical structure-preserving integrator for the same problem running alongside it from day one. It costs an hour, it is the control for every experiment afterwards, and on these pages it is the thing that made the failure obvious.

Having the classical baseline present from the start is the practical recommendation of the whole set.

Reading

Six, and where they fit

The foundation

Hairer, Lubich & Wanner, Geometric Numerical Integration (Springer, 2006) — why structure beats accuracy over long runs, done properly. Chapters 1 and 6 are all you need for everything on these pages, and it was written long before anyone tried to learn an integrator.

Leimkuhler & Reich, Simulating Hamiltonian Dynamics (CUP, 2004) — the same material with more worked mechanics.

Learning dynamics

Greydanus, Dzamba & Yosinski, Hamiltonian Neural Networks (2019) — learn the Hamiltonian, take the step symplectically, conserve energy by construction.

Chen et al., Neural Ordinary Differential Equations (2018) — the paper that made "the network is the right-hand side" standard.

Where it bites

Lam et al., GraphCast, Science (2023) — a learned weather model, with the rollout behaviour treated as a first class concern.

Vaswani et al., Attention Is All You Need (2017) — for the architecture itself, if you have not read it.

If there is time for one item, it is Hairer chapter 1: the backward-error argument is the rigorous version of this whole set.

Before you trust a rollout

Five checks, in order of cost

  1. Plot a conserved quantity over the full horizon. One plot. It would have revealed everything on these pages, and it is the check most often skipped.
  2. Run a classical structure-preserving scheme alongside. If leapfrog holds and your model does not, the problem is structure, not accuracy.
  3. Extract the linear map and take its eigenvalues. Where the dynamics are nearly linear, ∣λ∣|\lambda|∣λ∣ predicts the rollout before you run it.
  4. Run the exact rule through your own pipeline. Same discretisation, same precision. Without that control you cannot separate your model's error from your plumbing's.
  5. Repeat with several random starts. Here the failure direction flipped between runs. One run is an anecdote.

All five are cheap compared with training the model in the first place.

The three that actually bite

Judging a time-stepper by its one-step error — the failure is in the compounding, and the average cannot see it.
Confusing a good coefficient with good physics — error propagation can amplify it by an order of magnitude, as it did here.
Blaming the discretisation without testing it — on these pages the rounding turned out to be helping.

All three produce plausible output. None announces itself.

The companion sets
