# The Quant Toolkit — source

Build code for [*The Quant Toolkit: Physics, Mathematics and Statistics for Finance*](https://dipakmunshi87.github.io/ML_Stat_Notes/quant_toolkit.html),
a 22-chapter note with 25 computed figures. Every number quoted in the text is produced by the
scripts here with fixed random seeds; nothing is drawn from live market data.

## Layout

| File | What it does |
|---|---|
| `lib.py` | Shared helpers: validated colour palette, figure styling, `V(key, value)` to record a computed value, `save(fig, name)` |
| `compute_part1.py` | Chapters 1–6: discounting and bonds, fat tails, estimation/Sharpe statistics, covariance & PCA, heat equation, regression |
| `compute_part2.py` | Chapters 7–13: Brownian motion, Itô/GBM/OU, Black–Scholes, Greeks and hedging simulation, Merton & Heston smiles, Vasicek, trees / Crank–Nicolson / Monte Carlo / LSMC |
| `compute_part3.py` | Chapters 14–20: AR(1)/unit roots/cointegration/Kalman, GARCH MLE, Marchenko–Pastur and covariance cleaning, Markowitz/Kelly/risk parity, VaR/ES/EVT, ML signals with walk-forward CV, multiple-testing (max-Sharpe) simulations |
| `chapters/*.html` | Chapter sources. Maths is written as `$...$` / `$$...$$`; computed numbers are `{{v:key}}`; figures are `{{fig:name|caption}}` |
| `build.py` | Substitutes values and base64 figures into the chapters, builds the TOC and pager, then calls the renderer |
| `mathrender.js` | Server-side MathJax (TeX → SVG), so the page needs no JavaScript maths library at view time |
| `template.html` | Page shell: styles, paged navigation (Prev/Next, Contents, arrow keys) |
| `make_preview.py` | The 1200×630 social-preview image (implied-volatility surface) |

Outputs (`values.json`, `figs/*.png`, `quant_toolkit.html`) are regenerated by the scripts and are not committed here;
the published page lives one directory up.

## Reproduce

```bash
pip install numpy scipy matplotlib scikit-learn statsmodels
npm install            # installs mathjax-full (see package.json)
python compute_part1.py
python compute_part2.py
python compute_part3.py
python build.py        # -> quant_toolkit.html
python make_preview.py # -> quant_toolkit_preview.png (optional)
```

Part 2 takes about 15 s and Part 3 about a minute (the gradient-boosting walk-forward and the max-Sharpe simulations).

## Checks built into the pipeline

* `build.py` reports any `{{v:...}}` or `{{fig:...}}` placeholder that has no computed value or figure, and the number of equations rendered and any TeX errors.
* Several chapters cross-check an analytic result against a simulation inside the same script (Black–Scholes vs Monte Carlo, Heston Fourier price vs full-truncation Euler, Vasicek bond price vs rate-path simulation, binomial tree vs closed form, Cholesky sample covariance vs target).
