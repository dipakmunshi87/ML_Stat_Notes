Dipak Munshi · interactive notes

Notes and demonstrations
for physicists

Short, self-contained sets of pages on the statistical and computational methods that turn up again and again in physics — written from the equations outward, for readers who know physics but not necessarily the statistics jargon.

Every page runs in the browser with no server, no framework and no network: the equations are pre-rendered text and every figure is computed live in JavaScript, so each reload is a fresh realisation rather than a stored picture.

Using the pages

Moving around

← → or swipe move between slides. The bar across the top of every page jumps straight to any section.

The notes

N shows or hides the longer explanation under each slide — the part you would say out loud if you were presenting it.

Text size

A− and A+ in the bottom bar scale everything, which is what you want on a projector or a phone.

Without JavaScript

Each page degrades into one long scrolling document with every slide and all the notes visible. Only the live figures need JavaScript.
