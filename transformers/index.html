Transformers,
and physics

A transformer does one thing: the all-pairs sum you already write when you compute a force on a particle from every other particle. The only difference is that the kernel is learned from data instead of handed to you by Newton. That turns out to be the right operation for data that arrives as an unordered, variable-size collection of things — which is most of what physics produces.

Six demonstrations, each training a real transformer in your browser while you watch. Nothing here is a stored result.

The one equation everything follows from

Stack your objects as rows of XXX, make three copies of each row, score every pair, and average with those scores as weights:

Attn(X)=softmax ⁣(QK ⁣⊤dk)V,Q=XWQ, K=XWK, V=XWV.\mathrm{Attn}(X)=\mathrm{softmax}\!\left(\frac{QK^{\!\top}}{\sqrt{d_k}}\right)V, \qquad Q=XW_Q,\ K=XW_K,\ V=XW_V .Attn(X)=softmax(dk​​QK⊤​)V,Q=XWQ​, K=XWK​, V=XWV​.

Everything else follows. Each row of the weight matrix sums to one, so the output is an average of the values with coefficients decided by the data — a kernel, learned rather than assumed.

Nothing in the equation refers to order, so attention sees a set: shuffle the inputs and the outputs shuffle with them, exactly. Every pair is summed, so the cost grows as T2T^2T2 — the one real practical constraint. Forbid each object from seeing the ones after it and the same network becomes a generative model, which for a physicist is a transfer matrix with its entries left blank.

Physics picture

A Boltzmann weight. The scores are energies, the softmax is a partition function, and the size of q ⁣⋅ ⁣kq\!\cdot\!kq⋅k is an inverse temperature the network sets for itself. Cold means one term dominates — a lookup. Hot means everything contributes — an average. Training is cooling.

The sentence to remember

A transformer is the right default when your data is an unordered, variable-size collection of things that need not be alike, and the wrong default otherwise. On page 3 an ordinary network with thirty times the parameters never leaves the baseline on a task the transformer solves completely.

Four results from these pages

One line is load-bearing — and only sometimes

Removing 1/dk1/\sqrt{d_k}1/dk​​ at dk=64d_k=64dk​=64 takes the error from 0.015 to 0.599, worse than predicting zero, with the attention at chance. At dk=8d_k=8dk​=8 the identical change is invisible. Removing the residual connection or the layer norm costs nothing at one layer. Architectural pieces matter at the scale they were invented to fix.

Shape beats size

On a lookup over a set, an ordinary network with 87,809 parameters and four times the training never leaves the baseline. A transformer with 2,773 solves it completely, and then works unchanged on sets more than twice the size it was trained on. Shuffling the inputs changes its answer by 4×10−16 — rounding error.

One feature is worth three times the model

Classifying a toy jet as one-prong or two: 97.7% with ΔR2\Delta R^2ΔR2 supplied per constituent, 62.0% without it, 64.0% without it at 2.7 times the size. The effort belongs in the representation, not the parameter count — which is also what Particle Transformer found at production scale.

A generative model, checked against theory

A causal transformer shown nothing but sampled Ising chains — no energy, no β\betaβ, no formula — generates configurations whose correlation function reproduces tanh⁡kβ\tanh^k\betatanhkβ to a few per cent. It is also systematically over-correlated, which is exactly the kind of small bias that would propagate into a physical result unnoticed.

Five habits worth having

Do

  1. Gradient check the model against finite differences before training it.
  2. Overfit ten examples deliberately; if that fails, the bug is in the model.
  3. Put the physics in the features before putting parameters in the network.
  4. Beat a trivial baseline — the mean, a linear fit — and quote it.
  5. Hold out whole runs and edge regions, and report several seeds with the spread.

Don't

  1. Read attention maps as explanations; intervene and measure instead.
  2. Trust an ablation run at a different scale from the model you care about.
  3. Assume a surrogate knows it is off-distribution — it will answer confidently.
  4. Expect conservation laws, symmetry or extrapolation unless you built them in.
  5. Reach for a transformer when the data is a regular grid with local physics.
